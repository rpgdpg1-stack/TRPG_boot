# Скилы для claude.ai (обычный чат, не Claude Code)

Здесь лежат **версии для облака** — их надо загружать на claude.ai руками
(Настройки → Skills, или «Customize» в десктопном приложении).

Автоматического синка из Claude Code в claude.ai **не существует**: синхронизация
идёт только в обратную сторону (claude.ai → `~/.claude/skills/synced/`).

## Чем отличаются от основных скилов в `.claude/skills/`

1. **Только шесть полей frontmatter** — `name`, `description`, `license`, `compatibility`,
   `metadata`, `allowed-tools`. Любое другое (`when_to_use`, `disable-model-invocation`)
   ломает загрузку с ошибкой, а не игнорируется.
2. **Без ссылок на файлы кода** — в чате нет репозитория, пути к файлам бесполезны.
3. **Только визуал и продукт** — процесс, БД, гит и Figma-мост в чате не нужны.

## Что загружено на claude.ai

| Файл | Роль в чате |
|---|---|
| `trpg-ui.md` | дизайн-система: палитра, скругления, шрифты, отступы |
| `trpg-product-reviewer.md` | ревью экрана по скриншоту |

`trpg-workflow` и `trpg-supabase` в чат **не загружаем** — без доступа к коду и базе
они бесполезны, а место в списке скилов занимают.

## Когда обновлять

Когда в `.claude/skills/trpg-ui/SKILL.md` реально поменялись токены — палитра, шкала
отступов, скругления, шрифты. Раз в пару месяцев, не чаще. Мелкие правки компонентов
в чат тянуть не надо.
