# TRPG UI — дизайн-система (версия для чата)

Продукт: **TRPG** — фитнес-трекер, Telegram Mini App. Тёмная тема, мобильный экран.
Продукт держится на **простоте и минимализме**: игровые механики (XP, лиги, ранги,
награды, рейтинг) выпилены намеренно, название TRPG осталось историческим. Это справка по визуальному языку; кода и файлов здесь нет, поэтому
рассуждай в терминах токенов и правил, а не путей к файлам.

## Скругления

| Токен | Значение | Где |
|---|---|---|
| `--radius-pill` | 90px | таб-бар, табы, теги групп мышц, всё где радиус = половине высоты |
| `--radius-card` | 33px | карточки, модалки, аватары, широкие кнопки внизу экрана |
| `--radius-medium` | 20px | инпуты, тосты, плашки, попапы, кнопки в модалках |
| `--radius-small` | 10px | чипы-бейджи, скелетоны, превью-миниатюры |
| `--radius-xs` | 6px | галочки, полоски прогресса, мелкие бейджи |

Круглые икон-кнопки — `50%`. Вложенные скругления концентричны: **внутренний радиус =
внешний − padding контейнера** (контейнер 20px с padding 4px → внутренняя пилюля 16px).

## Цвет — два слоя

**Примитивы** (сырая палитра): `--neutral-0/500/600/850/900/950`, `--green-400/500/700`,
`--blue-400/500`, `--orange-500`, `--red-500`, `--purple-500`, `--pink-500`, `--yellow-500`.

**Семантика** (по назначению, ссылается на примитив): `--color-bg`, `--color-card`,
`--color-card-hover`, `--color-primary`, `--color-text`, `--color-text-secondary`.
Категории: `--cat-gym` (силовая, холодный металл `#AEB7C4`), `--cat-cardio`, `--cat-pool`,
`--cat-stretch`, `--cat-recovery`. Теги мест: `--tag-gym/home/outdoor`.

Полупрозрачные: `--color-border` (белый 7% — обводка-волосок), `--color-text-inactive`
(белый 50% — неактивные иконки таб-бара), `--color-surface-dim` (стекло таб-бара).

### Accent — цвет взаимодействия

`--accent` — цвет **только интерактивных элементов и состояний выбора** (принцип Apple,
Telegram, Linear). Пользователь выбирает 1 из 10 в настройках, тема меняется во всём
приложении. Дефолт — зелёный `#9ED153`.

Accent **не применяется** к смысловым цветам: группы мышц, виды спорта, теги, success,
error (красный), warning (жёлтый), info (голубой), графики, эмблемы. Они от темы не зависят.
Оранжевый закреплён за заметками (`--color-note`) — зелёный там занят действиями.

Правило: новый интерактивный элемент (кнопка, таб, чек, сегмент, выбор, ссылка) → accent.
Смысловая метка → свой семантический токен.

## Шрифты

- **Manrope** — основной текст **и все числа-метрики без исключения**.
- **Geist** — акцентный: заголовки, названия, секции-лейблы, буквы дней, инициал аватара.
  Жирность по иерархии: тайтлы ≥28px → `800`, акценты 15–27px → `700`, капс-лейблы ≤14px → `600`.

**Числа — всегда Manrope**, независимо от кегля: вес, время, счётчики, дистанция, серия,
рекорды, календарь. Правило из живой ошибки: вес стоял на Geist, поле ввода на Manrope —
при тапе цифра меняла начертание. Соседние метрики (95 кг и 2,8 км) обязаны читаться
одним рядом. Единица измерения при числе — тоже Manrope, мельче и серым.

Минимальный кегль — 11px, ниже не опускаться.

## Типо-иерархия — лестница из трёх уровней

1. **Главное значение** — `--color-text`, белый (число «2» тренировки).
2. **Название и контекст** — `--text-label`, белый 85% (Силовая, Плавание).
3. **Пояснение и подпись** — `--text-info`, белый 68% (750 м, время в скобках).

Не красить строку в один цвет: всё белое → плоско, всё серое → теряется смысл.
Цифры не красить в цвет вида — спорят с метриками выше.

## Отступы — база 4px

Шкала: `2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48`.
Значения вне шкалы (9, 10, 13, 14, 18, 22, 26, 30) не использовать — округлять к шагу.
Полушаги 2 и 6 — только для микро-зазоров внутри строки (иконка↔цифра, цифра↔единица).

**Лестница близости** — внутренний отступ всегда меньше внешнего, иначе группа распадается:

| Уровень | Значение |
|---|---|
| внутри элемента (иконка и подпись) | 2–4 |
| внутри группы (строки списка) | 6–8 |
| между связанными (карточки в списке) | 12 |
| поля экрана и паддинги карточек | 16 |
| между блоками | 20–24 |
| крупный разрыв | 32–48 |

## Общие правила

- Тач-таргеты — **не меньше 44px**.
- Приложение должно ощущаться частью телефона, а не сайтом в вебвью.
- Хардкод запрещён: любое значение цвета, отступа, радиуса, кегля — из токена.
  Нет подходящего → заводить новый с обоснованием, а не писать число по месту.
- Одинаковое значение, скопированное в трёх местах, — повод завести токен.
