# Тестовый аккаунт (прод-база)

Отладочный пользователь: смотреть на нём расчёты статистики, рекорды, календарь
и карточку профиля, не трогая настоящие данные.

| | |
|---|---|
| `users.id` | **14** |
| `telegram_id` | `999000001` |
| Имя / username | Тест Девов / `devtest` |
| Реферальный код | `ref_9c341a24` |

`telegram_id` взят из невозможного диапазона `999_000_xxx` — с настоящим
Telegram-пользователем он не пересечётся никогда.

## Где он виден

Нигде, кроме прямых запросов к базе. В друзья ни к кому не добавлен
(`friendships` пуст), поэтому в списках реальных пользователей не появляется.
Приватность открыта полностью (`show_stats`, `show_favorites`, `show_weights`),
чтобы проверять карточку друга во всех состояниях.

## Что в нём есть

- **11 завершённых тренировок**: 7 силовых (`prog_001`, дни A/B/C) и 4 заплыва
  (`swim_001`) с дистанциями 900–2250 м. Разбросаны от «вчера» до «95 дней
  назад» — календарь листается, периоды Неделя/Месяц/Год/Всё дают разные цифры.
- **5 рабочих весов**, максимум — приседания со штангой 110 кг (это и есть
  «Лучший результат» силовой).
- **3 любимых упражнения**.

## Как им пользоваться

Войти в приложение под ним **нельзя**: авторизация идёт через Edge Function
`telegram-auth`, которая проверяет HMAC-подпись initData от бота. Подделать её
на клиенте невозможно, а обходить проверку в коде ради отладки — открывать дыру,
которая рано или поздно уедет в прод.

Поэтому аккаунт для проверки **серверной** стороны — через SQL и вызов RPC:

```sql
-- Что отдадут «Лучшие результаты» и карточка профиля
select public.api_get_user_public_profile(14);

-- Сводка за период (аналог summarizeWorkouts на клиенте)
select count(*), sum(extract(epoch from (finished_at - started_at))/60)::int as minutes
from public.workouts
where user_id = 14 and finished_at >= date_trunc('month', now());
```

Визуальную часть по-прежнему удобнее проверять в браузере, подставляя данные в
`localStorage` (ключи `recent-workouts:*`, `personal-records`).

## Удалить, когда перестанет быть нужен

```sql
delete from public.user_favorite_exercises where user_id = 14;
delete from public.user_exercise_weights   where user_id = 14;
delete from public.workouts                where user_id = 14;
delete from public.users                   where id = 14;
```
